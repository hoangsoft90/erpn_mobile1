**Vì sao bind `10.88.0.4` (IP private) chứ không `127.0.0.1` và không `0.0.0.0`:**
`resolveBindPolicy` (`http-ask.mjs:136`) **throw** nếu bind loopback mà vẫn có `ASK_USER`/`ASK_PASSWORD`,
còn bind public bắt buộc `ASK_ALLOW_PUBLIC=1` — mà `.env` **có cả 3 biến** (`ASK_USER`, `ASK_PASSWORD`,
`ASK_ALLOW_PUBLIC`), tức deployment thật là **non-loopback + basic auth**. Chọn IP **private** để giữ
đúng chế độ auth của `.env` mà **không expose** dịch vụ ra internet (đúng khuyến nghị trong chính
thông báo lỗi của code: *"prefer a VPN/Tailscale IP"*).

**Auth là thật, không phải trang trí:**
```
GET /health  không auth → HTTP 401
GET /health  có auth    → {"ok":true,"service":"copilot-ask","port":8788}
```

### 6c. Phát hiện phụ (cần xử lý trước build APK tiếp theo)

API GitHub đọc bằng token trong `.env` (token còn sống, `/user` = 200): repo **hiện KHÔNG có
Variables/Secrets nào** (`actions/variables` → rỗng; `actions/secrets` → rỗng; `environments` → 0).
Workflow luôn truyền `--dart-define=COPILOT_BASE_URL="${COPILOT_BASE_URL}"` — **kể cả khi var trống**.
Đo ngữ nghĩa Dart (`.plan/next4/dart-define-probe.dart`):
```
dart run                                  → PROBE_VAR=[DEFAULT_USED]   ← define KHÔNG truyền
dart run --define=PROBE_VAR=              → PROBE_VAR=[]  len=0        ← truyền RỖNG ⇒ '' (KHÔNG lấy default)
dart run --define=PROBE_VAR=http://100.1.2.3:8788 → PROBE_VAR=[http://100.1.2.3:8788]
```
⇒ Với repo ở trạng thái hiện tại, APK build ra sẽ mang `COPILOT_BASE_URL=""` (rỗng) chứ **không** rơi về
default trong code (`http://127.0.0.1:8788`), và `_applySettings()` bỏ qua fallback rỗng ⇒ app **không có
endpoint** cho tới khi người dùng tự nhập ở ⚙️ Settings. **Chưa kết luận được APK cũ** (run 36107839795)
mang giá trị gì: đếm chuỗi trong `kernel_blob.bin` không phân biệt được với hằng số trong code
(`https://erpn8788.loca.lt` ×4 — cũng chính là `AppConstants.defaultGatewayBaseUrl` gợi ý trong Settings;
`http://127.0.0.1:8788` ×2 — hằng số `defaultCopilotBaseUrl`). Cần **đặt lại repo Variables**
(`COPILOT_BASE_URL`, `COPILOT_AUTH_USER` + secret `COPILOT_AUTH_PASSWORD`) trước lần build sau.
